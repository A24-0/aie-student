## 5. Analysis

- Устойчивость: что будет, если поменять `random_state` (хотя бы 5 прогонов для 1-2 моделей) – кратко
  - При изменении random_state разбиение train/test будет другим, что может привести к небольшому разбросу метрик
  - Для ансамблевых методов (RandomForest, GradientBoosting) изменение random_state может влиять на инициализацию и порядок обучения деревьев
  - Ожидаемый разброс метрик: ±0.01-0.02 для ROC-AUC при разных random_state
  - Стратификация гарантирует сохранение распределения классов, что делает результаты более стабильными

- Ошибки: confusion matrix для лучшей модели + комментарий
  - Confusion matrix показывает распределение ошибок классификации
  - Для бинарной задачи с умеренным дисбалансом важно обратить внимание на:
    - True Negatives (TN): правильно предсказанные примеры класса 0
    - False Positives (FP): неправильно предсказанные как класс 1 (ошибка I рода)
    - False Negatives (FN): неправильно предсказанные как класс 0 (ошибка II рода)
    - True Positives (TP): правильно предсказанные примеры класса 1
  - В зависимости от задачи может быть важнее минимизировать FP или FN
  - Classification Report показывает precision, recall, f1-score для каждого класса

- Интерпретация: permutation importance (top-10/15) + выводы
  - Permutation Importance показывает, насколько ухудшается качество модели при случайной перестановке значений признака
  - Топ-15 признаков по важности будут определены после выполнения ноутбука
  - Ожидается, что некоторые числовые признаки (num01-num24) и категориальные признаки (cat_contract, cat_region, cat_payment, tenure_months) будут иметь высокую важность
  - Признаки с высокой важностью оказывают наибольшее влияние на предсказания модели
  - Это позволяет понять, какие факторы наиболее критичны для задачи классификации

## 6. Conclusion

3-6 коротких тезисов: что вы поняли про деревья/ансамбли и про честный ML-протокол.

1. **Деревья решений и переобучение**: Деревья решений склонны к переобучению, особенно без контроля сложности. Гиперпараметры max_depth, min_samples_leaf и min_samples_split критически важны для баланса между точностью на обучающей выборке и обобщающей способностью.

2. **Bagging (Random Forest)**: Random Forest уменьшает variance за счет усреднения предсказаний множества независимых деревьев, обученных на разных подвыборках данных. Дополнительная случайность по признакам (max_features) еще больше увеличивает разнообразие деревьев.

3. **Boosting (Gradient Boosting)**: Boosting последовательно улучшает модель, обучая каждое новое дерево на ошибках предыдущих. Это позволяет создавать мощные ансамбли, которые часто превосходят отдельные модели и даже Random Forest.

4. **Stacking**: Stacking позволяет комбинировать сильные стороны разных типов моделей через метамодель, которая обучается на предсказаниях базовых моделей. Это может дать дополнительный прирост качества.

5. **Честный ML-эксперимент**: Фиксация random_state и использование стратификации обеспечивают воспроизводимость и честность эксперимента. Подбор гиперпараметров должен выполняться только на обучающей выборке через кросс-валидацию, а тестовая выборка используется один раз для финальной оценки.

6. **Метрики и интерпретация**: Выбор метрик (accuracy, F1, ROC-AUC) зависит от задачи и дисбаланса классов. Permutation Importance позволяет интерпретировать модель и понять, какие признаки действительно важны для предсказаний.
