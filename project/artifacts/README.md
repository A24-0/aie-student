# Артефакты

Создаются командой `python -m src.train`.

| Файл | Что это |
|------|---------|
| `dense.faiss` | FAISS-индекс плотных эмбеддингов |
| `chunks.json` | чанки с привязкой к документам-источникам |
| `index_meta.json` | модель эмбеддингов, число чанков, параметры чанкинга |
| `retrieval_comparison.csv` | сравнение BM25 / dense / hybrid по метрикам |
| `eval_per_query.csv` | результат по каждому запросу (для анализа ошибок) |
| `experiments.csv` / `experiments.jsonl` | лог всех прогонов (трекер экспериментов) |
| `training_summary.json` | финальная конфигурация и лучший прогон |

BM25-индекс отдельно не сохраняется — он дёшево пересобирается из `chunks.json` при загрузке.
