# Данные

Корпус собран вручную под учебный проект: справочные тексты по личным финансам.
Персональных и конфиденциальных данных нет — все формулировки общеобразовательные.

## Файлы

| Файл | Что внутри |
|------|------------|
| `corpus.json` | База знаний: `id`, `topic`, `title`, `text`. ~80 коротких статей по 13 темам |
| `eval.json` | Контрольные запросы: `query` (как спросил бы человек) и `relevant` (id релевантных документов) |

## Темы корпуса

deposits, credits, credit_cards, mortgage, taxes, investing, pension, insurance,
budget, emergency_fund, inflation, currency, security.

## Замечание про релевантность

Запросы в `eval.json` сформулированы своими словами, а не копией заголовка —
так оценка retrieval честнее. У части запросов несколько релевантных документов
(например, вычет по ипотеке упоминается и в теме ипотеки, и в теме налогов).

Корпус целиком лежит в репозитории, потому что он маленький. При его изменении
индексы нужно пересобрать: `python -m src.train`.
