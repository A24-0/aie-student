# Код проекта (`src/`)

| Папка / модуль | Назначение |
|----------------|------------|
| `config.py` | загрузка настроек из `configs/config.yaml` и переменных окружения |
| `logging_utils.py` | настройка логирования |
| `data/` | загрузка корпуса, чанкинг, препроцессинг для BM25 |
| `retrieval/` | эмбеддер, плотный индекс (FAISS), BM25, гибрид (RRF) |
| `rag/` | движок и генератор ответа |
| `eval/` | метрики retrieval и прогон оценки |
| `tracking/` | трекер экспериментов |
| `service/` | FastAPI-приложение |
| `train.py` | сборка индексов и эксперименты |

Запуск: `python -m src.train`, затем `python -m src.service.main`.
